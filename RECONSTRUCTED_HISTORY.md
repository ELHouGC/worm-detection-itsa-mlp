# Reconstructed history

This repository's initial source-file commits were reconstructed from the files'
recorded filesystem `LastWriteTime` values. Those timestamps were used as commit
dates and the files were added in chronological order.

This is not original Git history. The available timestamps do not verify the
contents of each file at that time, or the sequence of edits.
The commits therefore preserve the files available now, not verified historical
snapshots. Generated Python bytecode and notebook checkpoint files were omitted.
